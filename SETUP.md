## Environment

- [ ] Run `nix develop` (or `direnv allow` after reviewing `.envrc`) to enter the dev shell
- [ ] If not using Nix/direnv, install tools manually: `go 1.26.3`, `mise`, `golangci-lint`, `changie`, `gotestsum`, `goreleaser`

## Go module

- [ ] Run `mise run mod-tidy` to generate `go.sum` and `gomod2nix.toml`
- [ ] Run `mise run build` to verify the project compiles

## First release

When ready to cut a release:
1. `changie new` — describe changes
2. `mise run pre-release <major|minor|patch>` — batch + merge CHANGELOG
3. Open a PR, merge to main
4. `mise run release` — tag and push (CI publishes the release)
