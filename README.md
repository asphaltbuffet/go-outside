# go-outside

> Calculate if you should go outside based on current conditions.

## Installation

```bash
go install github.com/asphaltbuffet/go-outside@latest
```

Or with Nix:

```nix
# flake.nix input
go-outside.url = "github:asphaltbuffet/go-outside";
```
